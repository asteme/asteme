# For agents working on this repository

Read `MAINTAINING.md` first: who decides what, what you may change by yourself, and how a change travels. Then `CONTRIBUTING.md` for the layout and the rules for changes.

# Working rules

- Reference projects provide implementation evidence only.
- Distinguish specified behavior, implemented behavior, and measured results. Do not claim behavior is implemented or validated from old tests.
- Keep private transcripts, databases, research checkouts and generated experiment output outside this repository.
