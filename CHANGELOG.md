# Changelog

What changed in each version and why.

## 0.12.2

- **Fixed:** opening Asteme in DSH waited for everything remembered to be read for the panel (with a thousand memories, more than a megabyte) before it began to open the conversation, which needs none of it. Both now start at once. Opening the conversation also read the whole conversation three times over; it is read once and then only what was added, so a long conversation no longer makes it slower.
- **Fixed:** a memory opened from the list could only be closed, and closing took the list and the search in it away too. It now opens over the list, with the way back above its title (or Escape); the list is as you left it, and forgetting a memory from there takes you back to the list without it.
- **Changed:** in DSH, a reply no longer waits for a model to choose what to recall when a judge is set: the judge chooses, and the scene is read afterwards. With the model choosing, a reply waited nine seconds at the median and up to thirty; the judge takes under half a second. Over 2,122 answers given side by side the two agreed on 84.5%. "The model decides" is still in the settings. Without a judge, nothing changes.
- **Fixed:** the store grew with every reply far faster than what was remembered. Each reading before a reply kept a whole copy of every memory it looked at, with that memory's history: thirty thousand characters a reading, nine tenths of a store three months old. A reading now keeps what it decided and how each memory was found, and the memory itself is looked up by its id. Readings kept the old way are brought down a few hundred at a time soon after the update, and "Give space back" does all of them; the store shrinks by that much the next time it is given back.
- **Fixed:** the report for the developer came with an evidence file of fifty megabytes, too large to send. It now holds what a diagnosis reads: what you said, whole; replies to six hundred characters; readings as above, the newest three hundred; what tools did, counted with its size, except where a memory rests on it; receipts counted. The same store gives seven megabytes.
- **Fixed:** taking back something you said did not reach everything made from it. A reading before a reply is made from the last few messages, not only the one it answers, and when one of those was taken back the reading stayed, with a scene and reasons written from it; what was learned from how a memory was used stayed in readings that had used that memory by it; and what a model was writing in the background while something was taken back was kept. Now a reading names the messages it read and goes with any of them; everything a reading holds about a memory goes when that part drew on what was taken back; and what a model wrote is not kept if something it read was taken back while it wrote. Readings kept by earlier versions are treated as having read the messages just before them.
- **Fixed:** the same thing remembered twice in other words stayed twice. While idle, Asteme compared memories only when they were filed under the same subject or named the same person or thing. Two memories that say nearly the same thing are now put side by side too, and kept as one when they are the same.
- **Changed:** the films, in English, Chinese and Japanese, each its own story, made again from the first frame. They open on a still of the moment they are about (tonight's message, the reply that brings something back, and that memory open beside them with the sentence it rests on and the day it was said), because that still is what a README shows before anyone presses play. A promise is made and kept, and at the end one word is searched among the stars. The letters are large enough to read at the width GitHub shows a film, and nothing in them depends on the sound, which GitHub leaves off until asked. The page is filmed on the film's own clock, a thirtieth of a second at a time, so a busy machine cannot make it stutter. The score is one theme, Asteme's mark read as notes, played three ways (a hymn's plain chords in D for the English film, a flowing left hand in E-flat for the Japanese, open fifths and the five-note scale in F for the Chinese) and written to each film's own moments: it breaks off when the days begin to pass and goes on from the very note it stopped before when Asteme speaks first. The other five READMEs show the English film, and every README says in words what its film shows.
- **Changed:** the first screen of the README in every language. It now begins with one plain sentence saying what kind of thing Asteme is (a local AI you talk to, with long-term memory; a DeepSeek Harness plugin, a page of its own, or an MCP memory server), says what it needs before you start (Node 22.13, a model, about 400 MB of dependencies and a 120 MB embedding model downloaded once), and puts the note that it is still in development after the description, not before it. The plugin's own page (`packages/dsh-asteme`) has a picture, the same sentence, links to the other languages, and pictures for the catalogs that show them.
- **Fixed:** the README said the harness's own conversations are unchanged. They are not: with the plugin installed, the agent in DSH's own sessions does its work as before and speaks as Asteme, with the same name, way of speaking and memory. Only a session Asteme itself starts to hand work to stays plain DSH. The README in every language and the plugin's page now say what happens.
- **Fixed:** a day in another year did not say its year. A message from three Novembers ago was dated like one from this month, in the conversation's day lines, beside a message, and on a memory ("Learned Nov 14, 11:52 PM"). Dates in the current year read as before; any other year is named.
- **Added:** an opened memory says how its use has gone ("helped once", "was out of place in 2 situations"), in the memory beside the conversation. It was only in the panel inside DSH.
- **Fixed:** Chinese and Japanese were drawn with each other's letter shapes on some systems: the page asked only for "the system's font", and a system picks one set of shapes for the characters the two languages share. The page and the panel now name the faces for the language they are in.
- **Fixed:** the Portuguese of the panel mixed Portugal's words into Brazil's ("registo", "está a funcionar", "predefinição"). It is Brazil's throughout, and the page says so (`pt-BR`). Three sentences in the French, Portuguese and Russian READMEs addressed the reader differently from the rest of the page; they match now.
- **Fixed:** the Node that is needed is 22.13, not 22.5: `node:sqlite` works without a flag only from 22.13, and 0.12.1 stopped at start on 22.12. The badges, the text and `engines` say 22.13, and a test holds them together.
- **Fixed:** npmjs.com showed the Chinese README for `asteme` to everyone. The publishing step now sets the translations aside, so the English one is the page, with links to the rest.
- **Added:** a link to the site pasted into a chat or a post shows a card: the page's title, its first sentence and the banner in that language.
- **Fixed:** `npm run demo` ended with Node's notice that SQLite is experimental, which read as something having gone wrong. The demo no longer shows it.

## 0.12.1

Fixes for what 0.12.0 showed inside DeepSeek Harness and among the stars, and the project's site.

- **Fixed:** inside DSH, when the conversation could not be opened the panel said only "connection: invalid server-response failure". It now says what went wrong. The commonest case is a new install, where no model has been used in DSH yet: the panel says so in your language and asks you to send one message in a DSH session first.
- **Fixed:** inside DSH, the top of the conversation could lie under DSH's own bar when the side panel was folded away.
- **Changed:** opening Asteme in DSH shows its mark and nothing else until the conversation is there. There was a header with a turning refresh and "Loading…" with a spinner under it first.
- **Fixed:** lines no longer cross the whole page: in the sky behind the conversation, and for the moment it takes to go into the star view and back, when the stars also jumped once.
- **Changed:** among the stars, memories joined by a line stand together.
- **Changed:** among the stars, the wheel (or two fingers, `+`/`-`, a double press) takes you on through the sky toward the pointer and back the same way, instead of only bringing the sky nearer.
- **Added:** the site, <https://asteme.github.io/asteme/>, in eight languages: the conversation page's own sky, where each sentence about Asteme is a star, with the films and a plain page for reading.
- **Added:** on the site, a visitor may leave a line. It stays in their own browser unless they tick a box to put it in everyone's sky; then a person reads it before it is shown, and nothing is kept about who wrote it. There is no signing in.
- **Changed:** the README in every language says that Asteme hands work to an agent (it said this was still to come), leads to the site, and has a banner that says what its first sentence says.

## 0.12.0

Speaking of its own accord. Nothing here runs on a schedule of its own: what is new is something to say, an occasion to say it, and leave to say nothing.

- **Changed:** the films. There is one for each of three languages and each is its own story, not a translation (a mother who comes to visit; a book put off until forty; going home for the New Year). They end where Asteme is most itself: one word is searched among the stars, and everything ever said about it gathers, a line at a time. The score is an original piece for a real piano (the Salamander Grand Piano V3 samples by Alexander Holm, CC BY 3.0, credited in `NOTICE`). What made them is in `scripts/film/`, so they can be made again.
- **Changed:** `public/` holds the films and the stills and nothing else. The pages it once held were for the time before the code was published and said it was not available yet.
- **Added:** a reply may come as two or three messages. Where a person would send a second short message instead of one longer one (an afterthought, a question after the answer), the model may give `more` beside `reply`: one or two further messages, each stored and shown as a message of its own, a moment apart, with the writing dots between them. What belongs to the reply (a time it set, a face, the memories it used) stays with the first. Stopped in between, the rest is not said.
- **Changed:** the wording that tells the model about `more` and `hold`, after trying both with a real model. As first written it never used either: every reply was one message with a blank line where a person would have sent a second message, and something the user dreaded a week ahead was not kept. The answer's shape now names `more`; the rule says a new paragraph that turns from one thing to another is a message of its own, and that what has to be read whole stays whole; and `hold` says when to keep something (a thing ahead that weighs on the user, with nothing asked at a time). With that, the same conversation came as three messages, then two, a technical answer stayed one, and it kept "ask how the presentation went" and, a minute later with the presentation still a week off, said nothing on the user's return.
- **Fixed:** the room set aside for the fixed part of a speaking call (`fixedChars`) had fallen behind the rules it stands for: 20,500 characters for what is now 23,600. The fit to a model with a small window was off by that much, and a test of it failed only where file paths are longer (macOS, Windows). It is 24,500, and a test now holds it to the real size, so lengthening the rules without it fails everywhere and says why.
- **Added:** things kept in mind. `{act:"hold", about}` keeps something with no time on it to bring up when the user is next around: how a thing turned out, a question it was not the moment to ask. They are its own words, kept in the store (`brain:mind`, eight at most), shown to it as `INPUT.mind`, and shown to the user under "What it was doing" as "When you are next here", where each can be taken back. It lets one go itself with `unwake`.
- **Added:** coming back is an occasion. The page says when the user comes to the conversation (`/api/here`: on opening it and on turning back to it, at most once a minute). After three hours away (`absenceMs`), and only when something is kept in mind, Asteme is woken with "the user is back" and decides for itself whether to say one of those things. Saying nothing is the ordinary case and is not an error. Once for one coming back; never while it is thinking or work is out.
- **Changed:** when what it last brought up itself went unanswered, it is told to bring up less and keep less. The record of what was seen and answered was already in front of it (`INPUT.unanswered`); this is what it is for.
- **Changed:** what a reflection is sent. It was given the last twenty readings of any conversation, each with every candidate and every decision. On a store in use for some weeks that was most of the call (a median of 27,000 tokens in, 200 calls a day), and more than half of those readings belonged to another conversation. It is now given this turn's own readings whole, and of earlier ones only those of the same conversation that passed something on (six at most, with the decisions for what was passed), which is what laying a reported result to what produced it needs.
- **Changed:** a star that is chosen comes to you as its memory opens. It used to stay where it was, and on a wide screen the sheet that opened often lay across it. It is brought to the middle of the sky that the sheet leaves free.
- **Changed:** among the stars, the memories are all around you. They were laid out as a galaxy is, a disc looked at from outside and above, which is a picture of somebody else's sky. Now you are set down inside your own: stars in every direction, also behind, the newest nearest and the oldest furthest whichever way you look, and the eye is wider so that they go past as you turn. Far stars no longer fade to nothing (from inside, most of the sky is far). A young sky, too thin to stand in, is met from just outside and walked into; with every memory the place you are set down is further in. Pulled all the way back, the whole is a ball of stars. "Level the sky" takes you back to the middle.
- **Fixed:** the developer report said conversations that were not read were so "by the user's choice". Most are sessions one agent opened for another, set aside by design; it says so.
- **Fixed:** the conversation shook when a message arrived. The carrying added in an earlier candidate was measured on what the page reported, not on what was painted, and what was painted went down and up again: an animation begun late in a frame showed one frame at the new place first; a second change began the movement again from the start; and a conversation set back downward reached below the end of the page while it travelled, so the page was scrolled too far and had to come back. It is one quantity now, set by this code at each frame and never begun again, and it is taken off for the instant in which the page is measured or put at its end. Checked on the painted frames: one earlier bubble's position, frame by frame through three exchanges, moves one way only.
- **Changed:** what is on the page is carried to its new place and no longer jumps there. When a message arrives, the dots come or go, or a line is added under a message, the conversation above moves up or down in about a quarter of a second, and what has just arrived rises in with it. It is done in one place, by noticing the conversation change, so nothing that changes the conversation has to remember to do it. Not where the device asks for less movement.
- **Changed:** on a wide screen, the conversation makes room for a sheet at the pace the sheet comes in. It used to jump aside at once while the sheet was still sliding.
- **Fixed:** the mark shown while the conversation opens inside DSH moved down as it gave way. The room it stands in was only measured once the conversation's frame existed; it is measured from the first moment now, on the box around both.
- **Fixed:** opening the conversation inside DSH showed, for a second or two, a small ring and a paragraph of explanation in the top corner, then an empty frame, then the conversation; where the device asks for less movement the ring did not even turn. There is now the mark in the middle, its stars coming up one after another, and it stays until the conversation's page has loaded and then gives way to it.
- **Fixed:** the word "You" was written twice in each of the eight word files (the build warned of it on every run). Once now.

## 0.11.0

The first published version. Apache-2.0, with a NOTICE.

- **Fixed:** saying something always brings the newest into view, also after scrolling far back to read. Before, the conversation followed only when it was already at its end, and a message sent from further up went out unseen. (The same value was read, undeclared, after each reload of the state and failed silently there; it is one value now.)
- **Changed:** the license. `LICENSE` is Apache-2.0; `NOTICE` and `TRADEMARKS.md` say that the name and the mark are not covered by it. Versions before this one stay unlicensed.
- **Changed:** the memory settings were one long column of nine parts. They are four short pages: what is remembered; display and model; data; status. A change that fails says so beside the control that was pressed.
- **Changed:** how the plugin describes itself in DSH's list: what it is, and where to find it (the side bar to talk, Settings, Asteme to look after memory).
- **Changed:** two words at the top of the conversation, each the way into one whole thing. "Memory" opens everything about memory: search, the same memories as stars, and inside DSH each place where memory is looked after (the list, the last reply, activity, the charter, the memory settings). "Settings" is about the conversation only (look, Asteme itself, voice), as it was before a fourth tab was added to it. The memory settings are one view, shown in the panel and in DSH's own settings.
- **Fixed:** a model that offers six depths of thinking ran its choices off the side of the sheet. More than four choices are a list to pick from; fewer stand side by side and wrap if they must.
- **Fixed:** a long name for Asteme broke the settings' tabs onto two rows. The tabs keep one row and a long name is cut short there.
- **Changed:** the tab for Asteme itself is in four named parts (name and face; way of speaking; feeling and signs; what it is for), as the look is in three.
- **Fixed:** in the scene of its waking the first star was lit, went out, and came again as a falling star. The page reads the state more than once in that scene; a star that comes while the scene is on is now held unseen until the scene shows it, once.
- **Fixed:** seen again, the scene showed the first star standing for a moment when the dark lifted, before it went out and rose. It is held unseen from the start of the scene, with the rest.
- **Changed:** the way of speaking given when it is first woken goes into its charter, with its name. It used to be kept as a mood for now, apart from the charter, where nobody looking at the charter would find it.
- **Fixed:** the charter's form was filled once, when it was first shown, and went on showing that: a way of speaking or a name given afterwards in the conversation did not appear in it (it showed the old one, or nothing), and saving the form would have written the old over the new. It takes up what is stored whenever that changes; a field the user is in the middle of changing is left as they have it.
- **Fixed:** a newer page could be served over older code still running. The guard against that compared versions, and several builds carried one version: the page sent a way of speaking the old code did not know, and it was lost without a word. The code is compared by its contents now; and the page served is always the one that was loaded with the code, never a newer one from the disk. Candidates for a release carry their own number (`-rc.N`) from here on.
- **Added:** something long that the user sent is shown by its first lines, with "Show more" under it.
- **Added:** a new page in the conversation, one press at the top. From there Asteme speaks without the earlier exchanges in front of it, as if the talk had just begun. Nothing is erased: the earlier conversation is put away and can be looked at again, memories and their sources are as they were, work and times set go on; and one press joins the pages again.
- **Fixed:** when the model could not be reached (a key refused, for one), the page said only that nothing came back. It says why.
- **Added:** a picture handed over in the conversation is looked at before it is answered, where the model that speaks can see pictures: it is shown the picture with the user's words, and what it shows stands before the reply. Three at most. Where no model can see, the picture stays unseen and can be handed to a worker with its path, as a PDF or any other file is.
- **Changed:** the root package can be published as `asteme` on npm (the library and the command), with only what it runs on in it; a workflow publishes it and `dsh-asteme` when a person publishes a release.
- **Changed:** a picture in the conversation opens large over it, with its name, a way to close it (a press outside it, or Escape) and a link to open it in a tab; Tab stays within it while it is open. It used to open in another tab at once, which inside DSH took the person out of the conversation.
- **Fixed:** a time set more than some twenty-four days off made its timer fire at once, over and over. It is set for as far as a timer goes and looks again then.
- **Fixed:** a twenty-fifth face pushed the oldest out without a word. It is refused, and says why.
- **Removed:** the list of ways of speaking beside DSH's input. It was in the way, and its list drew wrongly there. The mark that says whether a conversation is remembered stays; the way of speaking is set in Asteme's settings or by asking.
- **Changed:** the README says how it is installed from this one repository, that DSH asks to allow three packages' install scripts, and in a few lines where it is going: memory now, hands next.
- **Added:** `MAINTAINING.md`, `SECURITY.md`, templates for issues and pull requests, and a release workflow: how the project is kept, written once for whoever keeps it.
